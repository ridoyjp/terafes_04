বাংলা নির্দেশনা

1. এই ZIP Extract করলে Terafes_04 ফোল্ডার পাবেন।
2. আগের Home Page, Robot, Voice এবং School Excel Data রাখা হয়েছে।
3. তথ্য মেনুর বাটন থাকবে। Chat-এর নিচে আর আলাদা Suggestion Button থাকবে না।

5. Worker-এর জন্য প্রয়োজনে cloudflare-worker ফোল্ডারে গিয়ে npm install চালান।
6. GitHub-এ কোড আপডেট করতে (আপনার Repo Folder-এ):
   git add .
   git commit -m "Keep festival navigation inside info menu"
   git push
7. Worker production deployment এই ZIP দিয়ে স্বয়ংক্রিয়ভাবে হয়নি।

এই ZIP-এ মূল প্রকল্পের অ্যাপ ও কনফিগারেশন রাখা হয়েছে, শুধু পুনরায় ইনস্টল করা যায় এমন node_modules বাদ দেওয়া হয়েছে।
