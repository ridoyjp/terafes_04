# TTC FESTIVAL 2026 — 最終検証・API停止時の動作

## 変更点

- Gemini API が429（利用上限）、503（混雑）またはネットワーク接続失敗でも、「情報一覧」の学校Excelに基づく9フロア・21掲載枠・34企画の案内は継続します。
- 選択した企画と教室、具体的な教室番号を入力した質問は、ブラウザー内の学校資料から回答するためGeminiの呼び出しを必要としません。
- 一般質問でAIが利用できない時は、原因に対応した説明と「情報一覧」を表示します。**AI停止中に一般知識質問へAI回答できるという意味ではありません。**
- 429の後は5分間、503の後は30秒間のAI呼び出し抑制を行い、連続失敗を防ぎます。この制限は情報一覧に適用しません。
- AI呼び出し中でもメニューを操作でき、企画の選択時には未完了のAI呼び出しを停止して学校情報を表示します。
- 企画の固定回答をGemini会話履歴へ混入させず、一般質問への誤誘導を防ぎます。
- ホーム画面・ロボット・デザイン・音声設定・Excel原本・Cloudflare Workerコードはそのままです。
